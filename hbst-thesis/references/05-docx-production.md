# DOCX 受控生产与版面细节

> 阶段三使用。目标：把优化后的论文稿落成**符合模板画像、可提交**的 `.docx`。本文给出用 python-docx / Word 自动化 / OOXML 直改都能落地的关键细节；能借用运行环境的 docx 技能/工具时可用，但规范以 writing-standards 为准，不得缩减。

## 1. 生产路径选择

- **受控生成（推荐）**：用 python-docx 按"分节→样式→内容→域→表格→页眉页脚"逐层构建，确定性最好。本技能 scripts/ 提供 docx 结构检查脚本（见 SKILL.md），生成后必跑。
- Word/WPS 自动化：用 COM/AppleScript 套学校模板改内容，保留模板原生样式，适合"有模板 + 少量内容替换"。
- Markdown→Pandoc 出 docx：**只作粗稿**。Pandoc 产物默认不是论文级排版（样式名、三线表、域、分节页码都要重做），若采用必须过完全部闸门才可声称交付。

## 2. 分节与页码（该校模板模型）

分 6 节（见 03-template-reverse §1.1），python-docx 用 `section.start_type = NEW_PAGE` 切节；每节设置：

1. 封面节：无页眉无页码；封面内容后即分节符。
2. 声明节：无页码（原文声明+授权书两文书**应各占一页**，writing-standards §2.1/4.2；真实样例曾挤一页，属应修复项）。
3. 中文摘要节：页脚插入 `PAGE` 域，页码格式 `upperRoman`、起始 1（显示 i）。
4. ABSTRACT 节：同上罗马续（不重置 start）。
5. 目录节：罗马续；目录必须是 `TOC \o "1-3"` 域（Word 域，非手打文字）。
6. 正文节：页眉"河北科技师范学院学士学位论文"；页脚 `PAGE` 域，格式 `decimal`、start=1；参考文献/致谢/附录与正文同一节或后续节（阿拉伯续，不重置）。

页脚页码域正确落法：页脚段落内放一个 `PAGE` 域（`fldChar begin / instrText PAGE / fldChar end`），并设置所在节的 `pgNumType` 格式；**不要手打数字**。目录与页脚域的显示值在校样前全选按 F9 更新（writing-standards §9）。

## 3. 样式与标题

- 标题 1/2/3 必须映射到 Word 内置标题样式（heading 1/2/3），TOC 与导航依赖它；禁止用"加粗+大字"冒充。
- 正文：宋体/Times New Roman 小四、两端对齐、首行缩进 2 字符、行距按模板（固定 20 磅或模板值，全篇统一）。
- 图题注段：居中、小五/五号；**在图下方**。表题注段：居中、在表**上方**，设"与下段同页"防与表拆开。

## 4. 三线表

判定标准（交付闸门）：
- 仅三条可见横线：顶线（约 1.5pt）、表头下栏目线（约 0.75pt）、底线（约 1.5pt）。
- 无竖线、无内部横线、**不是** Word `Table Grid` 样式。
- XML 层面：表级 `tblBorders` 只允许 top/bottom（及表头行底边框）；不得残留表级或单元格级 `insideH`/`insideV` 网格线（Word 会把继承网格渲染出来，肉眼初看"像三线"也不算过）。

python-docx 落法要点：建表后显式清掉 `Table Grid` 样式边框，改为对表设置上下边框 + 对表头行单元格设置下边框（栏目线）；数据行不加任何边框。生成后跑 `scripts/check_docx_structure.py` 的三线表检查。

## 5. 跨页长表

- 表头行设"重复标题行"（XML `w:tblHeader`），跨页自动带表头。
- 行设"不跨页断行"（`w:cantSplit`）。
- 表跨页处加可见续标段："续表 X.Y"（与 writing-standards §6.4 一致；表体本身**不要预拆成碎表**，先生成完整表再按分页结果决定续标）。
- 表标题与表体不被分页符拆开（标题段 keepNext）。

## 6. 图与题注

- 图注在图下、表注在表上，编号 `图X.Y`/`表X.Y`（该校样例用"图4.1"式，全角/半角空格以模板为准，全文统一）。
- 结构图优先可编辑源（.vsdx/.drawio）+ 高清 PNG 导出；最终 docx 至少嵌入 PNG。
- 截图宽度适配版心（约 10–15 cm），防止大图撑页留白（writing-standards §6.2/§10）。
- 图与"如图 X.Y 所示"引导句避免跨页相隔一页以上；题注不孤悬页底（keepNext）。

## 7. 参考文献与正文引用

- 参考文献条目：自动编号 `[1]…[n]` 或手写编号均可，但**格式统一**（GB/T 7714 顺序编码制，writing-standards §9）。
- 正文引用 `[n]` 与文末一一闭合：正文引用都有条目、条目不重复编号、无正文未引用的"背景文献"（有则单列说明）。
- 进阶（可选，视交付要求）：正文 `[n]` 做成 Word 内部超链接，指向文末条目书签（如 `ref_1`），Ctrl+点击可跳转；条目悬挂缩进。

## 8. 生成后必跑

1. `python scripts/check_text_quality.py <正文文本或docx文本导出>`：缺证措辞/编号闭合/引用闭合/字数。
2. `python scripts/check_docx_structure.py <paper.docx>`（能跑时）：分节数/标题样式/目录域/页脚 PAGE 域/三线表/续表表头。
3. 导出 PDF 后按 writing-standards §10 逐项人工核对版面（页码抽查、孤行、图注分离、空白页、跨页表头、乱码、截图变形）。

任何一项不过 → 修复 → 重跑 → 才可声称"可提交"。`.docx` 在闸门通过后又被改动 → 闸门证据失效，须重跑。
